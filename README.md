## 🚀 Como Executar os Scripts

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/stefanieduarda120-dev/programacao-com-python.git
   ```

2. **Acesse o diretório desejado (exemplo: Aula20):**
   ```bash
   cd programacao-com-python/"Aula20 Dicionário"
   ```

3. **Execute o arquivo Python desejado:**
   ```bash
   python nome_do_arquivo.py
   ```
